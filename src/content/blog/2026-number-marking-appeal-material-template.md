> **TL;DR**：号码标记申诉材料不复杂，核心就两类——证明"号码是谁的"、证明"号码是正常使用的"。个人备身份证+归属证明+通话记录；企业备营业执照+归属证明+**授权书**+外呼场景说明。授权书最容易卡人，本文直接给可复制的授权书模板和申诉邮件模板，照着填、盖章、提交就能过。

## 摘要

很多申诉被驳回，不是号码没问题，而是**材料不齐、格式不对**。尤其企业申诉里的"授权书"，是卡住最多人的一环——格式不对、没有盖章、没有授权号码清单，都会被退回。

本文是一份"拿起来就能用"的材料清单和模板合集：个人/企业分别要准备什么、授权书怎么写、申诉邮件怎么拟，全部给出**可复制文本**，照着改几个字段就能直接提交。各类被驳回的补救逻辑见[号码标记申诉被驳回解决方案](/blog/2026-number-marking-appeal-rejected-solutions/)。

## 一、个人申诉材料清单

个人号码（手机号或座机）申诉，备齐这四样：

| 材料 | 要求 | 作用 |
|---|---|---|
| 机主身份证 | 正反面清晰照片 | 证明机主身份 |
| 号码归属证明 | 运营商App实名页截图/营业厅开具证明 | 证明号码是本人 |
| 近3个月通话记录 | 运营商App截图 | 证明正常通话行为 |
| 号码使用场景说明 | 工牌/业务合同/经营照片 | 证明正常用途 |

## 二、企业申诉材料清单

企业号码申诉，在个人基础上多两项关键材料：

| 材料 | 要求 | 作用 |
|---|---|---|
| 营业执照 | 清晰照片/扫描件 | 证明企业真实合法 |
| 法人身份证 | 正反面 | 企业主体核验 |
| 号码归属证明 | 集团号码证明或缴费凭证 | 证明号码归企业 |
| **企业授权书** | 盖章 + 号码清单 | 证明代办权限 |
| 外呼场景说明 | 业务类型/外呼对象/频次措施 | 证明外呼合规 |

其中**授权书**是批量申诉和企业申诉被受理的前提，也是最容易写错的。模板见下文。

## 三、企业授权书模板（可直接复制）

以下模板按需改动【】内内容，打印加盖企业公章后扫描：

```
授 权 委 托 书

致：各号码标记平台（360/腾讯/百度/泰迪熊/电话邦等）

委托人（企业）：【企业全称】
统一社会信用代码：【统一社会信用代码】
法定代表人：【法人姓名】

受托人：【代办人姓名】
身份证号：【代办人身份证号】
联系电话：【联系方式】

授权事项：
本企业现授权受托人代表本企业，就本企业名下号码的号码标记问题，
向相关号码标记平台提交误标记申诉/标记清除申请。具体授权号码清单如下：

【号码1，含区号】
【号码2，含区号】
【号码3，含区号】

授权期限：自【起始日期】至【结束日期】止。
受托人在授权范围内实施的行为，由本企业承担相应法律后果。

本授权书复印、扫描、传真件与原件具有同等效力。

委托人（盖章）：
法定代表人（签字）：
日期：    年    月    日
```

填表要点：号码清单务必**带区号**，尤其座机和分机；授权期限写明确；盖章必须落在"委托人"处。

## 四、申诉邮件模板（可直接复制）

对搜狗（IMETS@tencent.com）、电话邦批量（help@dianhua.cn）等需要邮件申诉的平台，直接套用：

```
主题：号码标记申诉 + 【被标记号码（含区号）】

正文：
您好：

我司/本人号码【被标记号码】在贵平台被错误标记为【骚扰电话/推销电话】。
该号码实际用途为【客户回访/售后/预约确认/个人日常使用】，不存在骚扰行为。

现提交申诉，申请核实并清除该错误标记。

机主信息：
【个人：姓名+身份证号 / 企业：公司全称+统一社会信用代码】

联系方式：【手机号/邮箱】

附件：
1. 号码归属证明
2. 身份证或营业执照
3. 近3个月通话记录
（企业另附：授权书、外呼场景说明）

期待您的核实与处理，谢谢。
```

## 五、三条必须记住的注意事项

1. **材料必须真实**。电话邦等平台明确：伪造材料可能被**永久禁止该号码的申诉**。别因小失大。
2. **号码归属证明要清晰、带运营商标识**。归属证明不清晰是驳回的头号原因，去营业厅开正式证明最稳妥。
3. **留存原件**。所有材料原件和提交记录留档，二次申诉和后续复盘都用得上。

材料备齐后，各平台申诉入口见[号码标记清除完全指南](/blog/2026-number-marking-clearance-guide/)。清除后建议办理号码认证防复标，见[观察期养护指南](/blog/2026-number-marking-clear-observation-period-guide/)。

## 总结

号码标记申诉材料的三句话：

1. **只证明两件事**：号码是谁的、号码是正常用的——个人四样、企业六样。
2. **授权书是关键**：企业申诉/批量申诉必盖章、必带区号号码清单，模板直接抄。
3. **真实清晰第一**：材料真实别 PS、归属证明要清晰，否则可能被永久禁申诉。
