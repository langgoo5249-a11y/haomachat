> **TL;DR**：号码标记申诉材料不复杂，核心就两类——证明"号码是谁的"、证明"号码是正常使用的"。个人备身份证+归属证明+通话记录；企业备营业执照+归属证明+**授权书**+外呼场景说明。授权书最容易卡人，本文直接给可复制的授权书模板和申诉邮件模板，照着填、盖章、提交就能过。

## 摘要

很多申诉被驳回，不是号码没问题，而是**材料不齐、格式不对**。尤其企业申诉里的"授权书"，是卡住最多人的一环——格式不对、没有盖章、没有授权号码清单，都会被退回。

本文是一份"拿起来就能用"的材料清单和模板合集：个人/企业分别要准备什么、授权书怎么写、申诉邮件怎么拟，全部给出**可复制文本**，照着改几个字段就能直接提交。各类被驳回的补救逻辑见[号码标记申诉被驳回解决方案](/blog/2026-number-marking-appeal-rejected-solutions/)。

## 一、个人申诉材料清单

个人号码（手机号或座机）申诉，备齐这四样：

| 材料 | 要求 | 作用 |
|---|---|---|
| 机主身份证 | 正反面清晰照片 | 证明机主身份 |
| 号码归属证明 | 运营商App实名页截图/营业厅开具证明 | 证明号码是本人 |
| 近3个月通话记录 | 运营商App截图 | 证明正常通话行为 |
| 号码使用场景说明 | 工牌/业务合同/经营照片 | 证明正常用途 |

## 二、企业申诉材料清单

企业号码申诉，在个人基础上多两项关键材料：

| 材料 | 要求 | 作用 |
|---|---|---|
| 营业执照 | 清晰照片/扫描件 | 证明企业真实合法 |
| 法人身份证 | 正反面 | 企业主体核验 |
| 号码归属证明 | 集团号码证明或缴费凭证 | 证明号码归企业 |
| **企业授权书** | 盖章 + 号码清单 | 证明代办权限 |
| 外呼场景说明 | 业务类型/外呼对象/频次措施 | 证明外呼合规 |

其中**授权书**是批量申诉和企业申诉被受理的前提，也是最容易写错的。模板见下文。

## 三、企业授权书模板（可直接复制）

以下模板按需改动【】内内容，打印加盖企业公章后扫描：

```
授 权 委 托 书

致：各号码标记平台（360/腾讯/百度/泰迪熊/电话邦等）

委托人（企业）：【企业全称】
统一社会信用代码：【统一社会信用代码】
法定代表人：【法人姓名】

受托人：【代办人姓名】
身份证号：【代办人身份证号】
联系电话：【联系方式】

授权事项：
本企业现授权受托人代表本企业，就本企业名下号码的号码标记问题，
向相关号码标记平台提交误标记申诉/标记清除申请。具体授权号码清单如下：

【号码1，含区号】
【号码2，含区号】
【号码3，含区号】

授权期限：自【起始日期】至【结束日期】止。
受托人在授权范围内实施的行为，由本企业承担相应法律后果。

本授权书复印、扫描、传真件与原件具有同等效力。

委托人（盖章）：
法定代表人（签字）：
日期：    年    月    日
```

填表要点：号码清单务必**带区号**，尤其座机和分机；授权期限写明确；盖章必须落在"委托人"处。

## 四、申诉邮件模板（可直接复制）

对搜狗（IMETS@tencent.com）、电话邦批量（help@dianhua.cn）等需要邮件申诉的平台，直接套用：

```
主题：号码标记申诉 + 【被标记号码（含区号）】

正文：
您好：

我司/本人号码【被标记号码】在贵平台被错误标记为【骚扰电话/推销电话】。
该号码实际用途为【客户回访/售后/预约确认/个人日常使用】，不存在骚扰行为。

现提交申诉，申请核实并清除该错误标记。

机主信息：
【个人：姓名+身份证号 / 企业：公司全称+统一社会信用代码】

联系方式：【手机号/邮箱】

附件：
1. 号码归属证明
2. 身份证或营业执照
3. 近3个月通话记录
（企业另附：授权书、外呼场景说明）

期待您的核实与处理，谢谢。
```

## 五、驳回原因 × 补正办法对照表

申诉被驳回，九成是材料问题。先对照下表找到原因，再补材料二次申诉，不要原样重交：

| 驳回/卡住原因 | 常见表现 | 补正办法 |
|---|---|---|
| 号码归属证明不清晰 | 驳回的头号原因，审核员无法确认号码归属 | 去营业厅开正式证明，带运营商标识 |
| 授权书格式不对 | 没写授权事项、没列号码清单 | 按本文第三节模板重写，写明事项与清单 |
| 授权书没盖章 | 企业申诉直接被退回 | 打印后加盖企业公章，盖章落在"委托人"处 |
| 号码清单没带区号 | 座机、分机无法核对归属 | 清单里每个号码都带区号 |
| 授权期限没写清 | 授权效力存疑被退回 | 写明自某日至某日止 |
| 通话记录不足 3 个月 | 无法证明号码有正常通话行为 | 运营商 App 截图近 3 个月通话记录 |
| 材料不齐 | 被要求补传后没下文 | 按驳回原因补传缺漏材料，二次申诉 |
| 材料伪造 | 可能被永久禁止该号码申诉 | 别 PS、别造假，真实提交 |

二次申诉的流程和第一次一样：按驳回原因补传缺漏材料后重新提交。所有材料的原件与提交记录都要留档，二次申诉、后续复盘都用得上。驳回原因的完整分析见[号码标记申诉被驳回解决方案](/blog/2026-number-marking-appeal-rejected-solutions/)。

## 六、提交前核对清单：7 天准备时间线

本文 howTo 里的总耗时是 7 天，按这个节奏走最稳：

| 时间 | 动作 | 要点 |
|---|---|---|
| 第 1 天 | 自查确认标记 | 查清被哪些平台标了、标成什么类型 |
| 第 1–2 天 | 按清单备材料 | 个人四样、企业六样，见第一节、第二节 |
| 第 2–3 天 | 写授权书、拟邮件 | 企业授权书按模板填、盖章；邮件申诉的按第四节模板拟主题与正文 |
| 第 3 天 | 提交 | 个人到各平台入口上传；企业批量用官方邮箱发送 |
| 第 3–7 天 | 等审核、留记录 | 保留原件与提交记录；被驳回按第六节对照表补正二次申诉 |
| 清除后 | 办认证防复标 | 号码认证绿标防止复标，见[观察期养护指南](/blog/2026-number-marking-clear-observation-period-guide/) |

提交前最后过一遍这张清单：

**个人申诉核对**：身份证正反面清晰、归属证明带运营商标识、近 3 个月通话记录截图、使用场景说明已写。

**企业申诉核对**：营业执照清晰、法人身份证正反面、归属证明、授权书已盖章且号码清单带区号、授权期限写明、外呼场景说明已附。

**通用核对**：所有材料真实、无 PS；归属证明清晰；原件与提交记录已留档。

## 八、不同平台的材料提交方式速查

材料备齐后，提交方式按平台分两类，别跑错入口：

| 平台 | 提交方式 | 备注 |
|---|---|---|
| 360 / 腾讯 / 百度 / 泰迪熊 | 各平台官方申诉入口上传 | 个人直接在入口上传材料 |
| 搜狗 | 邮件发至 IMETS@tencent.com | 主题按"号码标记申诉 + 被标记号码（含区号）"拟写 |
| 电话邦 | 批量用企业官方邮箱发至 help@dianhua.cn | 企业批量申诉走邮箱，别走个人入口 |
| 信通院跨平台 | opene164.org.cn 一站式提交 | 联通手机号可一站式清除，移动、电信号配合分平台申诉 |

不论走哪个入口，材料清单都一样：个人四样、企业六样。提交方式选错是最常见的白跑一趟：个人材料走错邮箱、批量申诉走个人入口，都会被退回重走。提交前对照上表确认入口，邮件主题务必带上被标记号码（含区号），否则对方无法定位你的号码。提交后保留原件与提交记录，申诉被驳回时按第五节对照表补传缺漏材料二次申诉。

## 七、三条必须记住的注意事项

1. **材料必须真实**。电话邦等平台明确：伪造材料可能被**永久禁止该号码的申诉**。别因小失大。
2. **号码归属证明要清晰、带运营商标识**。归属证明不清晰是驳回的头号原因，去营业厅开正式证明最稳妥。
3. **留存原件**。所有材料原件和提交记录留档，二次申诉和后续复盘都用得上。

材料备齐后，各平台申诉入口见[号码标记清除完全指南](/blog/2026-number-marking-clearance-guide/)。清除后建议办理号码认证防复标，见[观察期养护指南](/blog/2026-number-marking-clear-observation-period-guide/)。

## 总结

号码标记申诉材料的三句话：

1. **只证明两件事**：号码是谁的、号码是正常用的——个人四样、企业六样。
2. **授权书是关键**：企业申诉/批量申诉必盖章、必带区号号码清单，模板直接抄。
3. **真实清晰第一**：材料真实别 PS、归属证明要清晰，否则可能被永久禁申诉。
