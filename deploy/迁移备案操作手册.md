# 号码通查 zangxixitech.cn — 迁移国内服务器 + ICP 备案操作手册

> 目标：把站点从 Cloudflare Pages + GitHub 部署，迁移到中国大陆服务器并完成 ICP 备案，
> 恢复百度抓取与自然流量。全程保持 URL 结构不变（`deploy/` 已做好 301 等价转换），
> 备案通过前保留 Cloudflare 一键回滚能力。

---

## 0. 五条铁律（先读，违反必被驳回或白干）

1. **备案接入商 = 服务器提供商**。用阿里云服务器就必须走阿里云备案；中途换服务器/换厂商 = 变更备案，要重走流程。→ 先定服务器，再定备案接入商。
2. **域名实名主体 = 备案主体**。企业备案要求域名「持有者」为企业或法人本人；不一致会被管局直接驳回。且域名需在有效期内、已完成实名认证（实名后 3~5 天才允许备案）。
3. **备案期间域名必须能解析到大陆服务器且 80 端口可访问**。Cloudflare 橙色云代理必须关闭，否则管局核验看不到真实站点。
4. **备案通过前不要删 Cloudflare DNS / Pages 配置**，保证可秒级回滚。
5. **网站内容不得涉及前置审批类目**（新闻、出版、教育、医疗、药品等），且网站名称、主体、内容要一致。

## 1. 前置决策确认（做之前先拍板）

| 决策项 | 建议 | 影响 |
|---|---|---|
| 备案主体 | **企业**（营业执照） | 个人备案对「科技/通讯/号码」类内容限制多、易驳回；企业更稳 |
| 服务器 / 接入商 | **阿里云**（轻量应用服务器） | 服务器与备案接入商必须是同一家 |
| 域名注册商 | 阿里云（若已在阿里云注册则最省事） | 非阿里云域名需改 NS 或做 CNAME 接入，增加步骤 |
| 备案期间是否需要站点在线 | 建议在线（本手册按在线迁移） | 若可短暂下线，可先关站备案再上 |

> 若域名 `zangxixitech.cn` 的实名主体不是本次备案主体，**先过户再备案**。

## 2. 阶段一：材料准备（企业备案）

- [ ] 营业执照（彩色扫描/拍照，剩余有效期 > 1 个月）
- [ ] 法定代表人身份证 正反面
- [ ] 网站负责人身份证 + 手机号 + 常用邮箱（可在阿里云 App 扫码人脸核验）
- [ ] 若网站负责人 ≠ 法人：**授权委托书**（模板阿里云提供）
- [ ] 域名证书（注册商后台下载）
- [ ] 企业真实办公地址、应急联系电话（会被核验，务必真实）
- [ ] 一个可接收工信部短信的手机号（核验短信 2 小时内必须回填）

## 3. 阶段二：购买服务器 + 申请备案服务号

1. 阿里云控制台 → 轻量应用服务器：
   - 地域：**华东1（杭州）** 或就近大陆地域
   - 规格：2 核 2G / 40G 起
   - 镜像：**Ubuntu 22.04 LTS**
   - **计费：包年包月 ≥ 3 个月**（按量付费/短于 3 个月无法生成备案服务号）
2. 安全组/防火墙放行：`22`（SSH）、`80`、`443`
3. 控制台 → 「备案」→ **申请备案服务号**（一台服务器可申请 5 个，记下服务号）
4. 记录：公网 IP、SSH 登录信息

> 备案服务号是提交备案的必需凭据，务必先拿到。

## 4. 阶段三：提交 ICP 备案

1. 打开 `https://beian.aliyun.com`，用阿里云账号登录，选择「开始备案」
2. 填写 **主体信息**（企业名称、证件号、法人、办公地址…）
3. 填写 **网站信息**：
   - 网站名称：建议填「**号码通查**」（与站内品牌一致，E-E-A-T 统一）
   - 域名：`zangxixitech.cn`、`www.zangxixitech.cn`
   - 服务内容：与站点实际相符
4. 上传材料 → 用 **阿里云 App 扫码做人脸核验** → 提交
5. **阿里云初审**：约 1~2 个工作日（可能电话核实）
6. **工信部短信核验**：收到短信后 **2 小时内**在指定链接完成核验，超时退回重来
7. **管局审核**：一般 3~20 个工作日（多数省份 3~7 天）
8. 通过后下发 **备案号**：在网站页脚展示备案号，并链接到 `https://beian.miit.gov.cn`
   - 可临时在 `src/layouts` 页脚加一行，或直接用现成组件占位，通过后填号

> 备案审核期间服务器要先能访问（80 通），所以**先做阶段四，再提交备案**的顺序更稳；
> 也可「买机→初审提交→并行搭环境」，两者不冲突。

## 6. 阶段五：部署站点与 API

### 6.1 本地生成产物

```bash
npm ci
npm run build         # 产出 dist/
npm run nginx:gen     # 生成 Nginx 重定向规则（map + 通配 snippet）
```

生成的两个文件（**勿手改**）：
- `deploy/nginx/conf.d/zangxixitech-redirect-map.conf` → 服务器 `/etc/nginx/conf.d/`
- `deploy/nginx/snippets/zangxixitech-wildcards.conf` → 服务器 `/etc/nginx/snippets/`

### 6.2 上传配置与站点

```bash
# 站点配置
scp deploy/nginx/sites-available/zangxixitech.cn.conf deploy@SERVER:/tmp/
scp deploy/nginx/conf.d/zangxixitech-redirect-map.conf  deploy@SERVER:/tmp/
scp deploy/nginx/snippets/zangxixitech-wildcards.conf   deploy@SERVER:/tmp/

# 服务器上安装配置
sudo mv /tmp/zangxixitech.cn.conf /etc/nginx/sites-available/
sudo mv /tmp/zangxixitech-redirect-map.conf /etc/nginx/conf.d/
sudo mv /tmp/zangxixitech-wildcards.conf /etc/nginx/snippets/
sudo ln -sf /etc/nginx/sites-available/zangxixitech.cn.conf /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

> 关键配置已内含：HTTPS、HSTS 等安全头、`map $uri` 精确 301（149 条）、
> 通配 301 snippet、`/api/` 反代、站长验证文件直出、静态资源强缓存。
> 详见 [zangxixitech.cn.conf](file:///workspace/haomachat/deploy/nginx/sites-available/zangxixitech.cn.conf)。

### 6.3 上传站点与 API

```bash
rsync -avz --delete dist/ deploy@SERVER:/var/www/zangxixitech.cn/
rsync -avz functions/api/attribution.js \
          deploy/server/server.mjs deploy/server/ecosystem.config.cjs \
          deploy@SERVER:/opt/haomachat/api/

# 启动 API（服务器上）
ssh deploy@SERVER 'cd /opt/haomachat/api && pm2 start ecosystem.config.cjs && pm2 save && pm2 startup'
```

> 原 Cloudflare Pages Function 由 [server.mjs](file:///workspace/haomachat/deploy/server/server.mjs) 等价替代，
> 复用 [attribution.js](file:///workspace/haomachat/functions/api/attribution.js) 业务逻辑，仅监听 `127.0.0.1:3000`，经 Nginx 反代。

## 7. 阶段六：HTTPS 证书

**方式 A：阿里云免费 DV 证书（推荐，与备案同平台）**
1. 阿里云控制台 → 数字证书管理服务 → 免费证书 → 申请（域名 `zangxixitech.cn` + `www`）
2. DNS 验证（在域名解析加一条 TXT，自动校验）
3. 下载 **Nginx 格式**，得到 `.pem` + `.key`
4. 放到服务器 `/etc/nginx/ssl/zangxixitech.cn.pem` / `.key`

**方式 B：Let's Encrypt（自动续期）**

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d zangxixitech.cn -d www.zangxixitech.cn
```

> 证书路径需与站点配置里的 `ssl_certificate` 一致（默认 `/etc/nginx/ssl/zangxixitech.cn.{pem,key}`）。

## 8. 阶段七：DNS 切换（备案通过后执行）

1. **先把 TTL 调低**（如 300s），提前 24h 减少切换抖动。
2. 关闭 Cloudflare 橙云代理（或直接迁移 NS）：
   - 方案一（保守）：Cloudflare 里把 A 记录改为 **DNS only（灰云）**，仍用 CF 解析
   - 方案二（彻底）：域名 NS 改为阿里云 DNS（`ns1.alidns.com` / `ns2.alidns.com`）
3. 阿里云云解析添加记录：
   - `@`     A → 服务器公网 IP
   - `www`   A → 服务器公网 IP
4. 验证：

```bash
dig +short zangxixitech.cn
curl -I https://zangxixitech.cn/          # 期望 200
curl -I https://zangxixitech.cn/sitemap.xml   # 期望 301 -> sitemap-index.xml
curl -s 'https://zangxixitech.cn/api/attribution?phone=13800138000'  # 期望 JSON
```

5. 确认无误后再在 Cloudflare 端保留配置 1~2 周，作为回滚保险。

## 附录 A：域名在西部数码 + 服务器在阿里云（当前情况）

**结论：可行。备案在阿里云办，域名不必转到阿里云。** 关系如下：

```
域名注册/实名 → 西部数码（WEST.CN，工信部批复注册商 ✓）
备案接入商     → 阿里云（与服务器绑定）
DNS 解析       → 西部数码 或 保留 Cloudflare（灰云）
站点服务器     → 阿里云轻量（备案服务号来自这里）
```

### A1. 西部数码侧要做的（域名相关）

1. **实名认证 + 主体一致**（最关键）：登录西部数码 → 域名管理，确认域名持有者名称
   = 本次备案主体（企业全称）。
   - 不一致 → 先做 **域名过户 / 变更持有者**，过户后实名信息同步到工信部库需 **3~5 天**，
     期间无法备案，务必提前办。
2. **域名在有效期内**（剩余 > 1 个月更稳）。
3. 下载 **域名证书**（备案时可能需上传）。
4. 确认域名没有处于 clientHold / 锁定状态。

### A2. 阿里云侧备案（非阿里云域名的差异）

阿里云备案系统里，域名注册商选「**非阿里云**」，会走「域名核验」流程：

- 阿里云先去 **工信部域名库** 查该域名的实名信息，与备案主体比对：
  - **能查到且一致** → 自动通过，最省事
  - **查不到 / 不一致** → 需按提示做 **域名所有权验证**：在域名解析里加一条阿里云指定的
    **TXT 记录**（在西部数码 DNS 或 Cloudflare 里加均可），验证通过后继续备案
- 其余流程与手册 §4 完全一致（初审 → 工信部短信核验 → 管局）。

> ⚠️ 常见驳回点：西部数码的实名信息与营业执照名称差一个字（如「有限公司」漏写）都会
> 导致核验失败。提交前逐字核对。

### A3. DNS 解析方案（二选一）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 保留 Cloudflare（推荐备案期用）** | CF 里把 A 记录改成 **DNS only（灰云）** 指向阿里云 IP | 改动最小，回滚快 | 仍依赖 CF 名称服务器 |
| **B. NS 迁回西部数码** | 在域名控制台把 NS 改为西部数码默认 DNS，在西部数码解析里加 A 记录 | 彻底摆脱 CF | NS 切换有生效延迟 |

**无论哪种**，备案期间都必须满足：`zangxixitech.cn` 与 `www` 的 A 记录 → 阿里云服务器 IP，
且 `http://zangxixitech.cn/`（80 端口）能正常打开。

> 建议：备案期用方案 A（灰云）先让站点可访问；备案通过并观察稳定后，再决定是否迁 NS 到西部数码
> 或阿里云解析。**不要开着橙云去备案**——管局核验会看到 Cloudflare 而非你的服务器。

### A4. 执行顺序（针对你的情况微调）

1. 西部数码：核对实名主体 / 需要则过户（预留 3~5 天同步）
2. 阿里云：买服务器 → 申请 **备案服务号**
3. 阿里云：搭服务器环境 + 部署站点（手册 §5、§6），确保 80 能访问
4. Cloudflare：A 记录改灰云 → 阿里云 IP（或先保持原状，等备案核验前再改）
5. 阿里云备案系统提交：域名注册商选「非阿里云」→ 按需做 TXT 域名核验
6. 初审 → 工信部短信核验 → 管局审核
7. 拿证后：页脚加备案号 → 配 HTTPS 证书（手册 §7）→ 跑 CI（手册 §9）→ 百度恢复（手册 §10）

### A5. 这个组合的三个坑

1. **实名不一致**：西部数码实名 ≠ 备案主体 → 直接驳回（最常见的失败原因）。
2. **实名同步延迟**：刚过户/刚实名就备案 → 工信部库查不到 → 核验失败，等 3~5 天再试。
3. **橙云未关**：A 记录仍是 CF 橙云代理 → 管局看不到大陆服务器 → 驳回或要求整改。

### B2. 填写主体信息

| 字段 | 填法 |
|---|---|
| 主办单位名称 | 营业执照上的**企业全称**（一字不差） |
| 统一社会信用代码 | 营业执照 18 位代码 |
| 证件住所 | 营业执照上的注册地址 |
| 通讯地址 | 真实办公地址（可能与注册地不同，必须真实） |
| 主体负责人 | 一般填**法人**：姓名/身份证号/手机/邮箱 |

> 主体负责人手机号会用于工信部短信核验，务必是法人本人且能收短信。

### B3. 填写网站信息

| 字段 | 填法 |
|---|---|
| 网站名称 | 建议「**号码通查**」；若管局驳回改「XX科技-号码通查」 |
| 网站域名 | `zangxixitech.cn`、`www.zangxixitech.cn` |
| 网站服务内容 | 选「**其他**」类，备注「号码归属地信息查询」 |
| 前置审批 | **无**（本类目不涉新闻/出版/教育/医疗等前置审批） |
| 网站负责人 | 可与主体负责人相同（法人）；不同则需授权书 |
| 网站语言 / 内容类型 | 中文 / 非经营性 |

> 网站名称规范：不得含「中国/国家/政府」等词，不得纯英文，需与主体或业务相关。

### B4. 域名核验（非阿里云域名必看）

提交域名后系统自动比对工信部域名库：

- **一致** → 直接过，跳到 B5
- **不一致 / 查不到** → 按页面提示做**域名所有权验证**：
  1. 系统给出一个 **TXT 记录**（主机记录 + 记录值）
  2. 到西部数码 DNS（或 Cloudflare）添加该 TXT
  3. 回备案页点「**验证**」，通过后继续
  4. 若仍失败，上传**域名证书**（西部数码后台下载）

### B5. 上传材料

- [ ] 营业执照（彩色、四角完整）
- [ ] 法人身份证 正反面
- [ ] 网站负责人身份证 正反面（若 ≠ 法人）
- [ ] **授权委托书**（网站负责人 ≠ 法人时，系统有模板，盖章）
- [ ] 域名证书（如 B4 提示需要）
- [ ] **核验单 / 承诺书**（系统自动生成 → 下载 → 打印签字盖章 → 扫描回传）

### B6. 人脸核验（阿里云 App）

1. 手机装「**阿里云**」App，登录同一账号
2. 备案页面会显示二维码 → App 扫码
3. 按提示完成**主体负责人 / 网站负责人人脸识别**

### B7. 提交 → 阿里云初审（约 1~2 个工作日）

- 保持电话畅通（阿里云可能用 95187 / 0571 号码**电话回访**核实信息）
- 材料有问题会被**退回修改**，按提示改完重新提交

### B8. 工信部短信核验（最容易翻车的一步）

- 提交管局后，会收到工信部 **12381** 短信
- 必须在 **2 小时内**完成核验（短信里有链接，或到 `beian.miit.gov.cn`）
- 主体负责人、网站负责人手机**都要**分别核验；**超时 → 本次备案作废，重来**

### B9. 管局审核（3~20 个工作日）

- 各省管局时长不同，多数 3~7 天
- 期间可能**电话抽查**，核实网站是否真实、内容是否与备案一致

### B10. 备案成功

1. 收到通过通知，得到备案号（如「浙ICP备2026xxxxxx号-1」）
2. **页脚展示**：在站点页脚加一行
   `浙ICP备2026xxxxxx号` → 超链接到 `https://beian.miit.gov.cn`
3. **公安联网备案**（另一件事，别漏）：备案通过后 **30 日内**，登录
   `https://www.beian.gov.cn` 做「公安联网备案」，拿到公安备案号也放到页脚

### B11. 备案后收尾

- [ ] 页脚展示 ICP 备案号 + 公安备案号
- [ ] 配 HTTPS 证书（手册 §7）
- [ ] 切 CI/CD（手册 §9）
- [ ] 百度站长平台恢复（手册 §10）
- [ ] 网站内容、主体、域名与备案保持一致，**变更需办变更备案**
- [ ] 服务器**按时续费**，欠费会导致备案接入异常被注销

## 附录 C：常见驳回原因与对应处理

| 驳回提示 | 原因 | 处理 |
|---|---|---|
| 域名未实名 / 实名不符 | 西部数码实名 ≠ 备案主体 | 过户后等 3~5 天再提交 |
| 网站名称不合规 | 含敏感词/纯英文/与主体无关 | 改成「XX科技-号码通查」 |
| 网站内容不符 | 站内出现与备案服务内容不符的经营性/违规内容 | 备案期先精简站内敏感内容 |
| 电话核验未接通 | 负责人漏接回访 | 保持畅通，接 95187 等 |
| 短信核验超时 | 2 小时内未回复 | 重新走一次提交 |
| 网站打不开 | 解析未指向服务器 / 80 被拦 / 橙云未关 | 见附录 A3 |
